# 🎬 MovieExplorer

A responsive Movie/TV Show Explorer built with React, React Router, and Tailwind CSS, using the TVMaze API.

## Features
- Home page with Hero Banner and navigation
- Movie Listing page with live search (by title)
- Responsive movie grid (1 column mobile, 3-4 columns desktop)
- Movie Details modal with poster, overview, rating, release date, and genre
- Fully responsive design

## Tech Stack
- React (Vite)
- React Router DOM
- Tailwind CSS
- TVMaze API

## Setup Instructions

```bash
git clone <your-repo-url>
cd Assignment-2
npm install
npm run dev
```

App runs at `http://localhost:5173`

## API Used
- `GET https://api.tvmaze.com/shows` — fetch all shows
- `GET https://api.tvmaze.com/search/shows?q=QUERY` — search shows by title
